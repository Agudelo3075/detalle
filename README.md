# 🌹 Detalle Especial para Briggite ❤️

Un proyecto romántico e interactivo desarrollado en **Astro**, diseñado especialmente para consentir, emocionar y sorprender a Briggite.

---

## ✨ Características y Detalles Incluidos

1. **🌸 Jardín Floral Animado e Interactivo (El centro del detalle)**:
   - Ventana con terraza botánica en tonos noche mágica y destellos dorados.
   - Gran título resplandeciente: **"Te amo, Briggite"**.
   - 5 flores botánicas vivas que se mecen con la brisa:
     - 🌹 **Rosa Eterna**: Con pétalos multicapa y espiral central.
     - 🌸 **Peonía Rosa**: Símbolo de ternura pura.
     - 🌻 **Girasol Radiante**: El centro de luz y alegría.
     - 💜 **Orquídea Mágica**: Elegancia y admiración.
     - 🌷 **Tulipán Escarlata**: Pasión y amor verdadero.
   - **Interacción**: Al tocar o pasar el mouse sobre cada flor, emite una campana armónica, confeti brillante y revela un pensamiento de amor secreto.

2. **💌 Carta de Amor con Lacre de Cera 3D**:
   - Sobre vintage con sello de cera que lleva el grabado *"Para Briggite"*.
   - Al tocar el sobre, el sello se rompe, el sobre se abre con animación tridimensional y despliega una hermosa carta apergaminada con una dedicatoria profunda y sincera.

3. **💖 El Frasquito de Razones para Amarte**:
   - Frasco de cristal ilustrado con corazones flotantes en su interior.
   - Botón interactivo para extraer razones de amor una por una con contador dinámico y lluvia de estrellas.

4. **💍 Mis Promesas Para Ti**:
   - Tarjetas de estilo *glassmorphism* con promesas reales de amor y cuidado.
   - **Botón de Besitos Virtuales**: Un pulsador interactivo que dispara una lluvia de corazones, besos voladores y acumula un contador ("+1,000,000 de besitos").

5. **🎟️ Vales de Amor Canjeables**:
   - Vales románticos interactivos (*Abrazo Infinito*, *Tarde de Pelis & Mimos*, *Cita Sorpresa*, *Tu Antojo Favorito*, *Masaje & Consentimiento*, *Tú Tienes la Razón*).
   - Al hacer clic en "Canjear Vale", se activa una celebración con confeti y un mensaje de confirmación para Briggite.

6. **🎵 Melodía Romántica Flotante ("Nuestra Melodía")**:
   - Widget con disco de vinilo que gira al reproducir.
   - Caja de música que interpreta una dulce melodía estilo *Canon / Lullaby* usando **Web Audio API** nativa (no depende de archivos externos ni internet).

7. **🌌 Atmósfera Mágica con Pétalos Cayendo**:
   - Canvas animado con física de pétalos de rosa flotando suavemente, luciérnagas y destellos que reaccionan a la brisa del cursor.
   - 100% responsivo para verse espectacular tanto en celular como en computadora.

---

## 🚀 Cómo ejecutar el proyecto

Para ver la página en tu navegador:

```bash
npm run dev
```

Luego abre en tu navegador el enlace que aparecerá (usualmente `http://localhost:4321`).

Para compilar para producción:
```bash
npm run build
```
Los archivos optimizados quedarán listos en la carpeta `dist/`.
